# 一期人工验收清单

> 自动化已覆盖：43 个单元/集成测试（`python -m pytest test/ -v`）与帧循环冒烟（`python main.py --frames 240`）。
> 以下为需要真人执行的验收项（本机自动化期间 X 键盘注入损坏，飞行动态项无法自动取证；真手柄流程全程未自动化）。

## 飞行手感（键盘：W/S 油门、A/D 偏航、↑↓ 俯仰、←→ 横滚）

1. **起飞**：W 推油门至 HUD 显示 ~38% 离地悬停（键盘油门每秒 ±100%，约 0.4s 到位）
2. **悬停**：无杆量时 HUD 横滚/俯仰读数稳定不振荡
3. **翻滚**：←/→ 按住满杆横滚，一圈约 0.54s（667°/s）；松开立即停转、无甩摆/续摆
4. **偏航**：A/D 旋转速率与横滚同量级，松开即停
5. **巡航**：满油门 + ↑↓ 杆前压俯冲，HUD 速度达 ~30 m/s 量级后不再上涨
6. **Esc 菜单**：暂停/继续/重置位置均生效；重置后回出生点、水平姿态、速度清零

## 参数与配置

7. **参数页**：全参数数值输入（PID/Rate/机体）改动保存后即时生效（飞行中可感知）；「恢复默认」回到标定值；保存后重启保持
8. **旧配置迁移**：一期开发期保存过旧量级 PID 的 `config/drone.json` 首次启动自动重置（其余字段保留）

## 手柄（HID，插上真遥控后）

9. **手动配置**：设备下拉出现 → 绑轴/反向 → 应用保存 → 预览条随杆动；重启保持
10. **配置向导**：选遥控类型（美/中/日手，已按标准 Mode 2/1/3 修正提示文案——**请确认与你的机型习惯一致**）→ 逐步打杆自动识别 → 验证页预览新绑定 → 完成保存
11. **拔出手柄**：飞行/配置中拔出 → 切键盘并提示，不崩溃

## 界面

12. **设置**：显示模式（全屏/固定大小窗口化/窗口化）切换与分辨率调整即时热重建（四态：窗口→改分辨率→全屏→切回）；窗口化可拖拽窗口边缘/最大化调分辨率，此时分辨率项只读；UI 随分辨率等比缩放（720p 基准）
13. **场景**：`scene/` 放入新场景（config.json 含 name/model[/scale/spawn]）即出现在列表；坏场景标注「无效」不崩溃

## 已知限制（一期）

- 本机帧率 ~22fps 时帧长被钳位到 33ms → 时间膨胀（动作比真实偏慢约 25%）；性能优化（直渲 VBO 重建）为二期方向
- 键盘兜底的瞬态满杆方波 + 0.38s 回中收敛：连续点按方向键手感应为「跟手不晃」，若偏软/偏硬可在参数页微调 PID P（即时生效）
