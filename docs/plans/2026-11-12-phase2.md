# FlamingSkyFPV 二期实现计划（M1-M4）

本计划为规格式实现计划：覆盖设计文档 §13 里程碑 M1-M4（预设存储与列表 UI / AUX 通道与输入层 / 飞控模式运行时 / MSP 身份组 spike）。M5-M7 依赖 M4 spike 产出的协议事实清单，另出第二份计划。每个任务给出精确接口与逐条行为断言，pytest 由执行者按断言逐条写出（先测后码）；纯 UI 任务以手动验收清单替代自动化断言。

**Goal:** 无人机预设管理（列表/编辑/复制/删除/旧档迁移）、AUX 开关通道与输入层遗留项（轴越界回中、HUD 输入徽标）、虚拟飞控运行时（ARM/ANGLE/HORIZON/反乌龟）、MSP 身份组服务器（Configurator 2026.6.2 连接识别）。

**Architecture:** 沿用一期 Screen 状态机 + imgui 全权 UI；依赖单向 `screens → physics/input/msp → config_store`；`msp/`、`physics/`、`input/` 禁 import soup3D/pygame/imgui，可独立无头单测。

**Tech Stack:** Python 3.10.6（系统 pyenv，不建 venv）、soup3D 7.0.0、pygame 2.6.1、pyimgui 2.0.0、PyBullet、pytest。

**Spec:** `docs/specs/2026-11-12-phase2-design.md`（§4 配置层 / §5 参数页 / §6 AUX 与输入 / §7 飞控模式 / §8 MSP / §10 错误表 / §11 测试策略）

## Global Constraints

- 依赖方向：`screens → physics/input/msp → config_store`；`msp/`、`physics/`、`input/` 禁 import 渲染/UI 库（soup3D/pygame/imgui）
- 回归基线：`python -m pytest test/ -v` 全绿（一期 71 项 + 新增）；参数模式零回归——`virtual_fc=False` 时一期飞行行为不变
- imgui 2.0 已知坑：`input_float`/`input_int`/`input_text` 返回 `(changed, value)`；中文字体加载后必须 `refresh_font_texture`；imgui 帧内禁止 GL 资源创建与字体图集操作（耗时操作走 App 帧边界标记机制）
- git 约定：中文提交信息 + `feat:`/`fix:`/`test:` 前缀 + 结尾 `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`；`test/`、`CLAUDE.md`、`todo.md`、`scene/*`、`.omc`、`.claude` 不入提交
- 测试惯例：纯逻辑测试直接构造对象断言（参考 `test/test_config_store.py`、`test/test_input.py`）；`FlightController`/`eval_boxes`/`msp` 可无头单测；UI 任务以手动验收清单替代 pytest
- box permanentId 与 MSP 命令号：以 Betaflight 4.5.x 源码与 Configurator 2026.6.2（`MSPHelper.js`/`MSPCodes.js`）核对；与本计划标注值不一致时按外部源码实现，并在提交说明中记录差异
